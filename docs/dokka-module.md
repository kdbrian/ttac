# Module TTac

API reference for TTac, generated by Dokka from the KDoc comments in the source.

For the narrative guide — how and why each system works, from Canvas basics to AI and networking — see the
[developer guide](../index.html).

# Package io.gh.kdbrian.ttac.game

Pure Kotlin game rules: the Tic-Tac-Toe board and AI, the Blocks falling-block engine and the Word Hive generator.
No Android dependencies, so everything here is unit-tested on the JVM.

# Package io.gh.kdbrian.ttac.data

Persisted state and the pure reducers that update it: records, streaks, medals, unlocks, heatmaps and the LAN board.

# Package io.gh.kdbrian.ttac.net

LAN multiplayer: the line-delimited JSON protocol, NSD discovery, TCP sessions, aliases, session codes and QR join links.

# Package io.gh.kdbrian.ttac.app

The `AppViewModel` (navigation, celebrations, wiring) and the `Match` state machine.

# Package io.gh.kdbrian.ttac.fx

Sound effects synthesised from oscillators at startup, and haptic waveforms.

# Package io.gh.kdbrian.ttac.ui.draw

Canvas drawing: marks, the board, heat effects, medals, arcade art, glyph icons and the animated backdrop.

# Package io.gh.kdbrian.ttac.ui.components

The bouncy glass UI kit, drawn with Compose modifiers and Canvas.
